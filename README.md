# manager-password-reset-302

nuclei-шаблон: GET на `/manager/index.php?a=0&hash=` с выключенными редиректами. Совпадение — ответ 302 с заголовком Location.

hash в запросе пустой. Если точка входа сброса пароля всё равно редиректит, скорее всего она не валидирует токен, но куда именно ведёт Location, надо смотреть руками. Ложных срабатываний хватает, слепо доверять списку не стоит.

запуск:

```
nuclei -t nuclei_manager_password_reset_302.yaml -l targets.txt
```
